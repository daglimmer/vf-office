- **Location:** `mission-control/argus-api` deployment + `argus-secrets`
- **Root Cause:** App resolving `argus-db` service to `84.29.88.9:5432` (external) instead of ClusterIP `10.43.14.191:5432`.
- **Action:**
  1. Check if `argus-db` service exists: `kubectl -n mission-control get svc argus-db`

     ```bash
     kubectl -n mission-control get secret argus-secrets -o jsonpath="{.data.DATABASE_URL}" | base64 -d
     ```
     Expected: `postgres://argus:***@argus-db.mission-control.svc.cluster.local:5432/argus`
  3. If secret is correct, debug why app ignores K8s DNS (check env overrides, `/etc/hosts`, or app config).
- **Verification:**
  ```bash
  kubectl -n mission-control logs -l app=argus-api --tail=20 | grep -i "connect\|ehostunreach\|timeout"
  ```
  **Expected:** *(no output)*  
  *If you see `Error: connect EHOSTUNREACH 84.29.88.9:5432` → FAIL.*

 3 packets transmitted, 3 received, 0% packet loss
